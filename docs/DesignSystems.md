# 🎨 Design System

## 💎 Principles
* **Glassmorphism First:** Use semi-transparent backgrounds with background blur to create depth.
* **Dark Mode Native:** The UI should feel like a premium, late-night developer tool.
* **Micro-interactions:** Cards should physically react (tilt/lift) when hovered over.

## 🖌️ Color Palette
* **Background Base:** Deep Space Black `#050505`
* **Glass Panels:** Translucent Slate `rgba(20, 20, 25, 0.4)`
* **Text Primary:** Pure White `#ffffff`
* **Text Secondary:** Muted Gray `#a1a1aa`
* **Accent 1 (Electric Blue):** `#3b82f6`
* **Accent 2 (Neon Purple):** `#8b5cf6`
* **Accent 3 (Cyber Pink):** `#ec4899`

## 🔤 Typography
* **Primary Font:** `Outfit` (Google Fonts)
* **Weights:** Light (300), Regular (400), Medium (500), Bold (700), Black (900)
* **Headings:** Bold and tightly spaced (letter-spacing: -1px).
* **Body:** Clean, legible, 1.1rem minimum for readability.
